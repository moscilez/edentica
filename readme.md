# Edentica для хакатона АЦР

Основной интерфейс теперь — студия методиста: запрос → уточнения → каркас и часы → согласование человеком → связанные материалы → проверки → экспорт. В режиме хакатона языковые модели работают только через Cloud.ru Evolution Foundation Models; для локальной проверки есть отдельный адаптер Codex.

Основной сервер: **Python 3.12 / FastAPI / psycopg 3 / PostgreSQL 18**. JavaScript остаётся в интерфейсе и проверенных правилах образовательных программ. Инструкция установки, переноса данных и запуска: [Python и PostgreSQL](docs/hackathon/python-postgres.md).

Запуск подготовленной среды: `npm.cmd run start:local`, затем http://localhost:3000/. Для генерации заполните CLOUDRU_API_KEY и CLOUDRU_MODEL в локальном .env и перезапустите сервер. Без настроек доступен явно помеченный подготовленный пример.

# EDENTICA

Рабочая локальная образовательная платформа на Node.js **22.16+** и SQLite. Основной сервер и интерфейс не требуют npm-зависимостей. PDF и импорт документов используют Python-пакеты из `requirements.txt`; в этом окружении они уже доступны в bundled runtime.

## Запуск

```powershell
node scripts/demo.mjs
npm.cmd start
```

Откройте http://localhost:3000. Создайте личный аккаунт (пароль от 10 символов). Демокурс доступен в каталоге. Для авторского сценария: Course Studio → черновик → заполнить модули и тесты → сохранить → опубликовать. Вопросы редактируются обычными полями: добавляйте варианты ответа и отмечайте правильный кружком слева. Для учебного: записаться → читать → сдавать тесты → сертификат. Для приглашений используйте опубликованный частный курс. Приглашение сохраняется в текущей вкладке и автоматически открывается после регистрации или входа.

На Windows для отдельного фонового процесса используйте `npm.cmd run start:local` из обычного локального терминала. Скрипт проверяет `/api/health`, не создаёт второй сервер и не останавливает чужие процессы. Журналы сохраняются в `data`. Обычная команда `npm.cmd start` работает, пока открыт терминал. При запуске через изолированные инструменты процесс может занимать порт, оставаясь недоступным браузеру; запускайте локальный сервер вне такой изоляции. Публичный сетевой доступ для этого не требуется.

Данные хранятся в `data/edentica.sqlite`. Сервер по умолчанию доступен только с локального компьютера. Для Docker подготовлены Dockerfile и compose.yaml с постоянным томом и локальной привязкой порта. Не запускайте Compose одновременно с текущим сервером на том же порту.

## Проверки

```powershell
npm.cmd test
npm.cmd run check
npm.cmd run backup
```

Проверяются учебный контур, девять типов заданий, ручная оценка, экзамен, PDF, изоляция организаций и источников, версии, Copilot, отмена генерации, media-адаптеры с тестовыми провайдерами, реальные импорты PDF/DOCX/PPTX/TXT, закрытые материалы, модерация и экспертные согласования. Все пользовательские данные тестов находятся в отдельных БД в памяти.

## Что реализовано

Регистрация, кабинеты, редактор курсов, девять типов заданий, ручная проверка, экзамен с таймером, прогресс и XP, PDF с QR, каталог, отзывы, обсуждения, избранное, подписки, рейтинги, версии, частные курсы, приглашения, организации, назначение обучения и CSV, модерация, библиотека источников, презентации, отдельные сайты курсов, светлая/тёмная темы. Добавлены реальные API-адаптеры AI Studio, Copilot, наставника, TTS и видео; без ключей они не запускают внешнюю генерацию.

## Конфигурация

Используйте `.env.example` как образец для локального `.env` или переменных окружения. Node автоматически читает `.env`, если он существует; существующие переменные окружения имеют приоритет. Не сохраняйте реальные ключи в исходниках и не отправляйте их в чат.

Для AI нужны OPENAI_API_KEY, доступная вашему аккаунту OPENAI_MODEL, актуальные тарифы и два дневных бюджета. Для речи дополнительно TTS_MODEL (`tts-1` или `tts-1-hd`), стандартный TTS_VOICE и тариф за символы. Для HeyGen — ключ, разрешённые библиотечные avatar/voice IDs, подтверждение прав и тариф видео. Перед отправкой материала автор/ученик подтверждает расходы и передачу. Автор отдельно разрешает внешний AI Tutor для своего курса.

Администратор выбирается через ADMIN_USER_ID: зарегистрируйте контролируемую учётную запись, скопируйте её UUID в профиле, настройте переменную на сервере и перезапустите. Email сам по себе не даёт привилегий. Для HTTPS устанавливайте COOKIE_SECURE=1 и корректный PUBLIC_URL; дополнительные имена сервера перечисляются в ALLOWED_HOSTS.

Вне bundled runtime нужен Python с пакетами requirements.txt и кириллическим TTF. PYTHON_PATH/CERTIFICATE_FONT переопределяют пути. PPTX-export использует `@oai/artifact-tool` из установленного runtime или ARTIFACT_NODE_MODULES. В обычном Linux-контейнере без этого runtime доступен просмотр и печать слайдов; кнопка PPTX выключена.

## Состояние и ограничения

Полный перечень функций, созданных/изменённых файлов и оставшихся требований: [docs/current-status.md](docs/current-status.md). Первоначальное техническое видение: [docs/architecture.md](docs/architecture.md). **Полное исходное ТЗ ещё не закрыто; production-готовность не заявляется.** Персональные аватары/клонирование голоса, платежи, custom domains, полная локализация и production-инфраструктура не реализованы. Реальные внешние API не проверены без ключей; тесты используют управляемые провайдеры.

Резервные копии создаются через `npm.cmd run backup` в `data/backups` и проверяются SQLite integrity_check. Восстановление выполняется оператором при остановленном сервере; никогда не заменяйте текущую БД без отдельной копии. Автоматическое восстановление из backup не запускалось.

Git-операции не выполнялись.

PDF и тестовый PPTX проверены визуально; PPTX проверен структурным валидатором и повторным импортом. Полная автоматическая визуальная проверка интерфейса недоступна из-за политики браузерного инструмента.

Сборка Docker проверена; все 11 тестов проходят на Windows и внутри Linux-контейнера. Compose валиден, контейнерный HTTP-запуск проверен. Для локального запуска через Docker используйте `docker compose up --build` после освобождения порта 3000; публичная привязка порта и production deployment в конфигурации не включены.
