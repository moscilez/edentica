# Репозиторий Gitea

Исходники опубликованы в ветке dev:
https://git.hub.gigaschool.ru/tochka-sborki-2026-team-074/project/src/branch/dev

Ветка main не изменялась. Новый dev содержит отдельную чистую историю: прежняя локальная история включала рабочие SQLite-базы, резервные копии и журналы, поэтому она не отправлялась. Локальные данные сохранены.

Для дальнейшей работы именно с Gitea используйте отдельный клон:

```powershell
git clone --branch dev https://git.hub.gigaschool.ru/tochka-sborki-2026-team-074/project.git edentica-gitea
cd edentica-gitea
```

Пароль вводится по запросу Git; он не записан в URL или файлах проекта. Исходная директория разработки сохраняет свой прежний репозиторий. Ветки dev и существующая main имеют разные исходные истории; автоматическое слияние или принудительная отправка в main не выполнялись.

Запуск: следуйте docs/docker.md. Файлы .env, data и output не входят в чистый снимок. Локальный Codex работает только на loopback; на ВМ используется выданный GigaChat-шлюз, а не прямой endpoint Cloud.ru Evolution.
