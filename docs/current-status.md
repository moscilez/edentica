# EDENTICA: фактическое состояние реализации

Обновлено 12 октября 2026 года. Этот документ описывает текущий код. Старые отчёты в architecture.md относятся к первоначальной итерации.

Правильные ответы не выдаются ученикам. Внутренний поиск, презентации и аудио ограничены открытыми модулями. XP не начисляются автору за собственные курсы и повторно за те же позиции в редакциях одного курса. Это защита от конкретных сценариев повторного начисления, а не утверждение о полной защите от сговора или ботов.

## Интеграции реализованы, реальные аккаунты не проверены

OpenAI Responses API создаёт структурированный черновик с лекциями и тестами. Автор принимает результат и затем редактирует его. Copilot меняет один выбранный модуль после предпросмотра; прежняя версия сохраняется, остальные модули не меняются, устаревшее предложение отклоняется. Наставник использует поиск по открытым текстовым фрагментам; AI-объяснение требует разрешения автора на передачу материалов и подтверждения ученика. Во время итогового экзамена он закрыт.

Media-адаптеры поддерживают OpenAI TTS (`tts-1`/`tts-1-hd`, стандартные голоса) и HeyGen V2 (библиотечный аватар, видео 720p, субтитры провайдера). MP3 хранится в БД; видео открывается по ссылке провайдера. Формат запросов и статусы проверены тестовыми провайдерами, реальные платные вызовы не выполнялись. API HeyGen V2 основан на документации поставщика; доступность должна быть проверена с конкретным аккаунтом.

Тарифы вводит оператор по текущим данным поставщика. Есть верхняя оценка LLM-запроса, приблизительная оценка речи/видео, дневные бюджеты на пользователя и на весь сервер. Ошибки и отмена сохраняют резерв: запрос мог быть оплачен. Отмена у Edentica не гарантирует отмену уже запущенной операции у внешнего поставщика. Счётчики токенов доступны для генерации курсов; полная сверка счетов всех провайдеров не реализована.

Официальные источники интеграций: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [Text-to-speech](https://developers.openai.com/api/docs/guides/text-to-speech), [HeyGen video workflow](https://github.com/heygen-com/skills-legacy/blob/master/skills/heygen/references/video-generation.md).

## Проверено

Автоматические сценарии: регистрация и права, тестирование и XP, экзамен и сертификат, ручная проверка, приватные курсы и приглашения, корпоративная изоляция, восстановление версий, Copilot с защитой от устаревшего результата, отмена AI, договорённый формат media-провайдеров, реальные PDF/DOCX/PPTX/TXT импорты, экспертные проверки и блокировки публикации.

Финальная проверка: 41 JavaScript-файл прошёл проверку синтаксиса; все 11 тестов прошли на Windows и в собранном Linux Docker-образе. Проверка Compose прошла. Страница, JS и API вернули HTTP 200 внутри контейнера и на локальном сервере после обновления. Резервная копия перед обновлением создана и прошла integrity_check. Для повторения используйте `npm.cmd run check`; контейнерный запуск проверен без настоящих API-ключей и пользовательских данных.

PDF просмотрен в PNG, включая длинное название. Тестовый PPTX прошёл проверки структуры, геометрии, шрифта и повторного импорта; слайд просмотрен в PNG. Это проверки образцов, не обещание отсутствия любых проблем в произвольном пользовательском контенте. Автоматическая визуальная проверка всего интерфейса недоступна из-за политики инструмента браузера.

## Что не реализовано и не считается готовым

- Создание персонального аватара из фото, клонирование голоса, проверка личности и хранение биометрических образцов. Центр цифровой личности сейчас ведёт только журнал согласий. Биометрические материалы не принимаются.
- Композиция преподавателя со слайдами, монтаж сцен через FFmpeg, визуальные лекции, STT и редактирование субтитров. Субтитры видео делает внешний провайдер.
- Генеративные иллюстрации и диаграммы презентаций, отдельный редактор слайдов, фирменные шаблоны сертификатов и подписи автора.
- Структурированная карта компетенций по отдельным вопросам, расширенные достижения, сезонные рейтинги, точная адаптивная образовательная траектория и полноценный многомодульный Copilot.
- Платежи и подписки, собственные домены и DNS-проверка, OAuth/MFA, email verification и восстановление пароля, полная локализация интерфейса.
- PostgreSQL/Redis/pgvector, отдельные workers, S3/CDN, полнофункциональная observability/CI/CD, автоматическая проверка фактов по источникам, формальная проверка GDPR/WCAG и production security assessment.

Это работающая локальная платформа с существенной частью основного контура. Полное исходное ТЗ ещё не закрыто. Коммерческая production-готовность не заявляется. Ключи отсутствуют, поэтому реальные AI/media-вызовы не проверены. SQLite используется одним сервером; sensitive-текст в БД не шифруется отдельно от защиты диска/ОС. Истечение подписанных ссылок видеопровайдера и его удалённые ресурсы требуют отдельной политики хранения.
