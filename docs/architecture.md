# Архитектура Эдентики

Рабочий сервер — Python/FastAPI; хранение — PostgreSQL 18. JavaScript работает в браузере. Docker Compose запускает frontend (Nginx), backend и db; test/test-db используют отдельные базы. Единственная backend-реплика управляет заданиями; несколько worker-процессов пока не поддерживаются.

## Создание программы

1. backend/contracts.py проверяет типы внешних данных. backend/planning.py извлекает явные ограничения и сохраняет их приоритет над моделью. Недостающие тип и часы нельзя угадать по длительности.
2. backend/skills.py описывает отдельные навыки разбора, смысловой структуры, лекции, оценивания и общих разделов. backend/programs.py оркестрирует этапы, контрольные точки и восстановление.
3. build_skeleton считает часы и календарь. У занятий есть week/day, часы и allocations по темам; аттестация хранится отдельно от модулей. Каркас проходит серверную проверку и требует явного утверждения человеком с digest/revision.
4. Материалы создаются по урокам, готовые результаты сохраняются до следующего внешнего вызова. При изменении модуля другие модули сохраняются. Повторы/кеш не заменяют проверку результата.
5. backend/validation.py и acceptance.py независимо проверяют суммы, связи, требования запроса, тесты, задания, портфолио и слайды. canonical.py формирует числовые разделы из того же плана, что используется таблицами.
6. research.py получает первичные документы из референсов, поискового API и тематического каталога. net.py ограничивает внешние запросы публичными HTTPS-адресами. Полученный текст не считается автоматически достоверным.
7. standards.py содержит проверенные реквизиты и известные коды функций. Факт наличия кода, тематическая применимость и действующая редакция — разные свойства; последние проверяет эксперт. Модель не может присвоить себе подтверждение.
8. docx_export.py, slides.py и exports.py формируют черновики без внешних процессов, npm и Node.js. В ZIP есть отчёт, JSON, GIFT, DOCX, слайды модулей и целевые слайды с manifest.json.

## Надёжность и конфигурация

Settings — единый контракт режима/провайдера. В hackathon запрещены произвольные API и Codex, включая ранее сохранённые пользовательские подключения. Fernet шифрует личные ключи. preflight проверяет форму обязательных настроек, health — БД. Внешние временные ошибки повторяются ограниченно; неоплаченный кеш и оплаченные невалидные ответы учитываются раздельно.

Задания исполняются внутри одного процесса; после аварийного перезапуска помечаются interrupted и продолжаются по решению человека. Это не распределённая очередь и не гарантия выполнения при недоступности модели или квоты. Исторические server.mjs/src не участвуют в контейнерном сценарии.
