# Эдентика: запуск и проверка хакатонного решения

Рабочий стек: Python/FastAPI, PostgreSQL, JavaScript, Docker Compose. Node.js и npm не требуются для серверного запуска, правил, DOCX или PPTX.

Единственная актуальная инструкция конфигурации и API — [docs/workflow.md](../workflow.md).
Развёртывание на ВМ — [Docker](../docker.md). Локальная разработка — [Python и PostgreSQL](python-postgres.md).

В режиме hackathon код допускает только выданный шлюз GIGASCHOOL или Cloud.ru Evolution с разрешёнными семействами моделей. Именование OPENAI_* обозначает совместимый протокол, а не разрешение использовать провайдера OpenAI. Codex доступен только в отдельном локальном режиме.

Сквозной сценарий: запрос/референсы → уточнения → смысловой каркас → точное распределение часов и календарь → явное согласование методистом → материалы уроков → независимые проверки → черновик DOCX/PPTX/JSON/GIFT/ZIP. /api/programs и совместимый /api/agent используют один планировщик и один генератор материалов.

Пять исходных запросов доступны как тестовые данные в tests_python/fixtures/case-requests.json. Они не являются демонстрационными программами или готовыми ответами. Реальный прогон: `python scripts/verify-case-matrix.py --full`; использует настроенную модель, временную БД и платные токены. Подробнее — [контракт сценария](../workflow.md).
