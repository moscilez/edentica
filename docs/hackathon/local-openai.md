# Локальная проверка через подписку ChatGPT/Codex

Для временной проверки разрешён официальный Codex CLI, авторизованный через ChatGPT. API-ключ не нужен. Сервер вызывает `codex exec` с сохранённой CLI-авторизацией. Авторизационные файлы приложение не читает и не копирует.

В локальном `.env`:

```dotenv
EDENTICA_MODE=local
LLM_PROVIDER=codex
CODEX_CLI_PATH=полный_путь_к_codex.exe
CODEX_MODEL=
```

Пустой CODEX_MODEL использует модель CLI по умолчанию. Войдите через `codex login`, если `codex login status` не подтверждает ChatGPT. После изменения настроек перезапустите сервер. Статус «OpenAI · локальная проверка» означает успешное обнаружение CLI и его входа; доступность генерации подтверждается реальным запросом.

Это расходует лимит вашей подписки. В интерфейсе и JSON сохраняются токены и провайдер. Денежная стоимость OpenAI не вычисляется по тарифам Cloud.ru; расход разных провайдеров разделяется в `usage.byProvider`.

Вызовы выполняются в отдельной временной директории с read-only sandbox. Подключения приложений, плагины, браузер, shell и дополнительные агенты отключены, пользовательский config не загружается. Данные передаются через stdin; пароли БД и API-ключи удаляются из окружения дочернего процесса. Отмена задачи завершает процесс CLI. Каждый вызов ограничен 150 секундами; ошибки JSON и методические ошибки обрабатываются существующим механизмом проверки и повторной генерации.

Для хакатона верните `EDENTICA_MODE=hackathon` и `LLM_PROVIDER=cloudru`, настройте CLOUDRU_API_KEY и CLOUDRU_MODEL. При попытке включить Codex в hackathon сервер откажется запускаться. Codex также запрещает привязку сервера к публичному HOST: используйте localhost, 127.0.0.1 или ::1. Docker по умолчанию использует Cloud.ru и не включает личную авторизацию Codex. Локальные тесты OpenAI не подтверждают качество, скорость или стоимость Cloud.ru.

Автоматические тесты не вызывают реальную модель. Отдельный, явно запускаемый `python scripts/verify-codex-generation.py --full` использует лимит подписки и проверяет генерацию 16-часовой программы в отдельной временной БД. Результаты сохраняются в `output/codex-real-check`, затем тестовая БД удаляется. Программы пользователей основной базы не изменяются.

Официальная документация: [неинтерактивный Codex](https://developers.openai.com/codex/noninteractive), [параметры CLI](https://learn.chatgpt.com/docs/cli/reference).

## Фактическая проверка 16 октября 2026

Реальный прогон общеразвивающей программы Python на 16 часов завершён через подписку Codex: 3 модуля, 5 компетенций, итоговый статус draft_ready, ошибок структурной проверки нет. Разбор и каркас заняли 109,41 с, полный прогон — 799,55 с. Выполнено 10 модельных вызовов, включая автоматические исправления; полученная статистика — 136 295 входных и 41 634 выходных токена. Это статистика теста Codex, не цена и не измерение скорости Cloud.ru. Источники и педагогическое качество по-прежнему требуют проверки методистом.

Отчёт и JSON комплекта сохранены локально в output/codex-real-check. Тестовая PostgreSQL-база удалена после завершения. Автоматические тесты: 16 passed; браузерная проверка режима OpenAI и навигации прошла без JavaScript-ошибок.
